\# F1 NFC-Powered PCB



A batteryless Formula 1-inspired PCB designed using KiCad.



\## Features

\- NFC energy harvesting

\- ATtiny1616 microcontroller

\- ST25DV04K NFC IC

\- 15 charlieplexed LEDs

\- Custom NFC antenna



\## Software

\- KiCad 10
